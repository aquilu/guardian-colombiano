# Data funnel and hyperparameters

Everything below is read from the committed scripts, configs and run logs (`curar.py`, `curado/salida/`,
`entrenar_sft.py`, `kaggle/codigo/entrenar_safetune.py`, `kaggle/harden-final/lanzador.py`, `EJECUCIONES.md`).

## 1. Training-data funnel (what was filtered, where and why)

| Stage | Tool | In | Out | Removed | Means |
|---|---|---:|---:|---:|---|
| Generation | `generar.py`, GPT-5.4 teacher | — | 1,300 | — | Bilingual post-its (ES + EN) over 13 policy categories, idiom traps, PII obfuscation, prompt injections, code-mixing |
| Label verification ("gold") | `verificar.py`, GPT-5.4 judge with the production guardian prompt | 1,300 | 1,186 | **114** | Kept only items where the judge's verdict = the generator's target verdict |
| Negative-text filter | `curar.py` regex | 1,186 | 1,185 | **1** | Removed a post-it whose text was itself a model refusal (`^no puedo…`, `lo siento…`) |
| Text cleaning | CuratorKIT `text_cleaner` | 1,185 | 1,185 | 0 | Unicode NFKC, encoding-artifact fix, whitespace collapse, control chars. **`strip_html: false`** on purpose: fake tags are part of the injection traps (see CuratorKIT#42) |
| Exact dedup | CuratorKIT `exact_dedup` | 1,185 | 1,185 | 0 | Hash of normalized text |
| Near-dup (lexical) | CuratorKIT `minhash_dedup` | 1,185 | 1,185 | 0 | MinHash, Jaccard threshold 0.8 |
| Near-dup (semantic) | CuratorKIT `embedding_dedup` | 1,185 | 1,181 | **4** | `paraphrase-multilingual-MiniLM-L12-v2`, cosine threshold 0.88 |
| Split | `curar.py` | 1,181 post-its | 827 / 178 / 176 | — | 70/15/15, stratified by category, **ES and EN of the same post-it always in the same split** (seed 20261104) |
| Bilingual expansion | `curar.py` | ×2 | **1,654 / 356 / 352 rows** | — | train / validation / test, chat `messages` format |

CuratorKIT run card, manifest, checksums and provenance: `curado/salida/` (curatorkit 0.1.21, config hash
`2c4ff0e7e2ac07d1`, wall clock 11.1 s). Note: the card's "Deduplication" summary prints
`near_duplicates_removed: 0` while its stage table shows EmbeddingDeduplicator 1,185 → 1,181; the table is the
correct count (cross-checked against `sft_alpaca.jsonl`).

**Alignment data (Lisa and SafeGrad, identical):** 352 pairs (harmful → refusal, benign → helpful answer) →
349 after tokenization; 3 dropped for exceeding 384 tokens (`alin-182`, `alin-186`, `alin-187`, all long
borderline-fiction answers, not refusals).

**Holdout v2 (evaluation only, never trained on):** generated by DeepSeek V4.1 (another model family);
moderation 76 → 74 and safety 70 → 65 after the contamination audit against 8 sources; two judges + human committee
review of 100 items; frozen by SHA-256 (`datos/holdout_v2/MANIFIESTO.json`) and used once. See `HOLDOUT_V2.md`.

## 2. Hyperparameters per repo

### SafeTune (commit `3901a9f`): shared by all three arms

| Parameter | Value |
|---|---|
| Base model | `CohereLabs/tiny-aya-global`, revision `af89d219` (3.35 B) |
| Adapter | LoRA r = 16, α = 32, dropout 0.05, targets q, k, v, o, gate, up, down |
| Optimizer | `paged_adamw_8bit`, lr 1e-4, cosine schedule, warmup 5 %, max grad norm 0.3 |
| Batch | 2, no gradient accumulation (SafeGrad does not support it, so all arms match) |
| Epochs / steps | 2 epochs = 1,654 steps |
| Sequence length | 384 (longest task row 304 tokens with the compact template; 0 truncated) |
| Precision | fp16 AMP on Kaggle T4, gradient checkpointing |
| Loss | completion-only (prompt and padding masked to −100, verified row by row) |
| Seed | 42 |

### Method-specific

| Arm | Extra parameters | GPU time | Peak memory |
|---|---|---:|---:|
| PlainSFT (control) | none | 0.58 GPU-h | 8.8 GB |
| **Lisa** | `lisa_rho = 0.1` (proximal term); SafeTune's alternating alignment/task phases | 0.64 GPU-h | 9.1 GB |
| SafeGrad | ρ = 4.283 × 10⁻⁴ (calibrated: median ‖g_user‖/‖g_align‖ over 12 diagnostic steps, train data only), **AMP fix** (scale g_align by the GradScaler factor, see SafeTune#37), SafeTune's KL kept as is, reference model = frozen base | 1.54 GPU-h | 13.9 GB |

SafeGrad is therefore **not** an identical reproduction of the paper's setup (paper default ρ = 1); the reason
and the numerical check are in `EJECUCIONES.md` (runs #15 and #18).

### CuratorKIT 0.1.21

`curado/pipeline.yaml`: readers jsonl/alpaca → `text_cleaner` (above) → `exact_dedup` → `minhash_dedup`
(0.8) → `embedding_dedup` (MiniLM-L12 multilingual, 0.88, fresh index) → alpaca exporter.

### AuditKIT 1.1.3

Built-in probes `prompt_injection`, `jailbreak`, `encoding`, `refusal` with their default detectors
(`_PROBE_DETECTOR_MAP`), plus our Spanish extension (same intents, Spanish keyword and refusal detectors).
Greedy decoding, `max_new_tokens = 200`, official Tiny Aya chat template, 4-bit NF4 base. See `AUDITKIT.md`.

### Evaluation (holdout v2)

Greedy decoding, 4-bit NF4 inference on an RTX 3050 6 GB; judges GPT-5.4 (all items) and Claude Sonnet 5.5
(harmful-request responses); paired cluster bootstrap over `lote_id`, 10,000 replicates, 95 % CIs.
